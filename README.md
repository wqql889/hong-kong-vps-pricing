## 同样 1 核 1G、同样 $5，四个套餐差在哪

差在线路和流量，不差在 CPU。

优化线路给大陆访客用。第三方测评记录的上游是 Megalayer，三网直连优化，电信回程走 CN2 精品网，联通走 4837。国际线路走国际带宽，大陆访问会绕路，海外访客反而更快。

流量那一栏要算一下。10M 不限流量的理论峰值是 1.25MB/s，按满速跑一个月约 3.2TB；20M/1TB 的峰值是 2.5MB/s，满速跑 4.7 天就把 1TB 用完了。所以「不限流量」适合持续稳定输出，「20M/1TB」适合短时高并发、总量可控的业务。两种计费逻辑没有谁更划算，看你自己的流量曲线。

选法很直接：访客在大陆、日 IP 几千、页面体积 1MB 以内，HK-VP01 更稳；做 API、活动页、突发下载，HK-VP02 的 20M 端口更快，但要盯着流量条。访客在海外，HK-VG01 的 20M 不限比 10M 优化线路更实用。

## 2M 带宽的机器，什么人真的够用

2M 带宽理论下载速度约 256KB/s。一个 1MB 的页面，单人打开要 4 秒，10 个人同时点进来就排队。31IDC 那台 1 核 2G、2M 带宽的机器报 ¥28/月，定位是测试学习和小并发应用，这个价格对得起它的带宽。

日 IP 几百的展示站、企业官网、询盘页，2M 撑得住。日 IP 过千，页面里有商品图、轮播、统计脚本，10M 起步。这个判断不用看商家宣传，用带宽换算就能得出。
